# TRI-13 — Structured environmental gradient

Recovery of known habitat, diversity, taxon, and pathway gradients.

The deterministic fixture contains 75 libraries, 60 batch-local control links, paired or explicitly single-end FASTQs, assay-specific abundance scales, read origins, ASV truth, artificial references, precomputed profiles, machine-readable assertions, taxonomy mappings, contamination truth, QC expectations, pathways, checksums, and provenance.

Regenerate from the repository root:

```bash
python3 scripts/generate_benchmark_datasets.py --dataset TRI-13
```
