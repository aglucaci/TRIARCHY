# Code of conduct

TRIARCHY follows the Contributor Covenant Code of Conduct, version 2.1.

Project spaces should be respectful, professional and focused on making the
software scientifically useful. Harassment, intimidation, personal attacks and
discriminatory language are not acceptable.

Report conduct concerns to the maintainer contact listed in the current
release notes or manuscript. Maintainers will review reports, protect private
information when possible and take proportionate action, which may include
moderation, temporary restrictions or removal from project spaces.

The full Contributor Covenant text is available at
https://www.contributor-covenant.org/version/2/1/code_of_conduct/.
